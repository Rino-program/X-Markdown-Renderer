# X Markdown Renderer

X (旧Twitter) のポストに書かれたMarkdown記法を、美しく読みやすいフォーマットへ自動レンダリングするGoogle Chrome拡張機能です。

---

## 🌟 特徴

- **公式UIに自然に馴染むデザイン**
  - ポスト本来のフォント（TwitterChirp等）、フォントサイズ、行間をそのまま引き継ぐため、違和感がありません。
- **スマートな「原文 / MD」切り替えボタン**
  - 右上ヘッダー（Grokマークの左隣）に邪魔にならない角丸ピルボタンを配置。(MD対応投稿のみ)
  - 通常時は控えめな透過度（`0.15`）でタイムライン閲覧の邪魔をせず、カーソルを合わせた時だけスッと認識できる明るさ（`0.60`）に変化します。
  - 引用ポスト枠内でも右上に綺麗に回り込んで配置されます。
- **豊富なMarkdown記法に対応**
  - 見出し (`#` 〜 `######`)
  - コードブロック (`` ``` ``) / インラインコード (`` ` ``)
  - テーブル（表組み）
  - タスクリスト (`- [ ]`, `- [x]`)
  - 引用ブロック (`>`)
  - リスト（箇条書き・番号付き）
  - 太字 (`**` / `__`)、斜体 (`*` / `_`)、打ち消し線 (`~~`)
  - リンク (`[text](url)`)、URL自動リンク、ハッシュタグ、メンション
- **安全・軽量設計**
  - 外部サーバーへの通信は一切なし（完全ローカル動作）。
  - `innerHTML` を使わず、安全なDOM構築によりXSSリスクを排除。
  - 投稿作成画面（コンポーザー）での干渉を防ぐ保護機能を内蔵。

---

## 📥 インストール方法

1. 本リポジトリ（またはフォルダ）をPCに保存します。
2. Google Chromeを開き、URLバーに `chrome://extensions/` を入力して開きます。
3. 画面右上の **「デベロッパーモード」** をONにします。
4. 左上の **「パッケージ化されていない拡張機能を読み込む」** をクリックします。
5. ファイル一式が入ったフォルダを選択します。
6. X (https://x.com) を開き、更新（F5）すると有効になります。

---

## ⚙️ 設定

ツールバーの拡張機能アイコンをクリックすると、以下の設定を切り替えられます：

- **Markdown変換を有効にする**: 拡張機能全体のON/OFF
- **すべてのポストを変換**:
  - `OFF`（推奨）: Markdown記法が含まれるポストのみ自動変換
  - `ON`: すべてのポストを変換対象にする
